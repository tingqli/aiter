## atomic_footprint.py: 64 lanes x 4 B contiguous per instruction, footprint cycled
agent     footprint     1 MB:  267.7 G atomics/s  1.07 TB/s payload
agent     footprint     4 MB:  271.7 G atomics/s  1.09 TB/s
agent     footprint    16 MB:  274.5 G atomics/s  1.10 TB/s
agent     footprint    64 MB:  293.6 G atomics/s  1.17 TB/s
agent     footprint   256 MB:  285.7 G atomics/s  1.14 TB/s
agent     footprint  1024 MB:  287.9 G atomics/s  1.15 TB/s
workgroup footprint     1 MB:  268.6 G atomics/s  1.07 TB/s
workgroup footprint  1024 MB:  288.0 G atomics/s  1.15 TB/s
# -> ~1.1 TB/s even when the whole footprint sits in L2: the limit is the L2
#    atomic unit, not misses / coherence scope.

## atomic_lanes.py: same 128 MB, same atomic count, two lane layouts
coalesced (32 lanes / 128 B line / instruction):  115.6 us = 1.16 TB/s
strided   ( 8 lanes / 128 B line / instruction):  463.3 us = 0.29 TB/s
# -> cost is per request (cache line), not per lane. The Down epilogue holds
#    8 consecutive BF16 (16 B) per lane, 8 lanes per row: as packed atomics that
#    is the strided layout.
